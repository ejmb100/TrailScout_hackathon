# TrailScout Data Sources

TrailScout should prefer open/public and official sources. Commercial/community trail apps may be linked for user research or comparison, but must not be scraped or used as backend data without a license.

| Source | Current Use | Access Method | License / Terms Notes | Priority | Limitations | Attribution Requirement | Confidence |
| --- | --- | --- | --- | --- | --- | --- | --- |
| OpenStreetMap / Overpass | Trail relations, trail/path/track ways, broad trail geometry and tags. | Same-origin `/api/overpass` proxy; dev middleware mirrors route. | ODbL; attribution required; derived data obligations apply. | High broad coverage fallback. | Community-maintained; geometry may be segment-only; tags incomplete. | Show OSM/source label and warn users to verify access/conditions. | Medium for route relations, lower for way segments. |
| USDA Forest Service EDW trails | National Forest System trail geometry and managed-use tags. | Runtime ArcGIS REST query in `officialTrailService.ts`. | Public federal data; verify service terms before commercial scaling. | High where available. | Current endpoint may return zero for some bboxes; closures/permits not complete. | Show USDA Forest Service / forest name when available. | High for geometry, medium for conditions. |
| USFS EDW recreation sites | Campgrounds, camping areas, trailheads, water/fee/open season fields. | Runtime ArcGIS REST query in `campsiteService.ts`. | Public federal data; verify current availability with land manager. | High for federal campsite context. | Not a reservation/permit source; may include day-use/trailhead records. | Show USFS/EDW campsite disclaimer. | Medium-high for facility existence, medium-low for availability. |
| Recreation.gov / RIDB | Federal facilities, campgrounds, permit areas, reservation URLs/status fields. | Server proxy `/api/ridb`; `RIDB_API_KEY` required on server. | Public RIDB API; key required; comply with Recreation.gov terms. | High for reservation and official facility enrichment. | Current implementation fetches `/facilities`; campsite-level endpoint is TODO. | Preserve facility URL, last updated, reservable/enabled flags. | High for Recreation.gov-managed facilities. |
| COTREX | Colorado trail geometry, length, elevation, manager, access, surface, official trail URL. | ArcGIS FeatureServer in `cotrexService.ts`. | Public state trail data; confirm terms for production/commercial use. | High for Colorado discovery. | Colorado only; geometry can be simplified; availability/permits not complete. | Show COTREX label and official trail URL where present. | High for Colorado route metadata, medium for live conditions. |
| USGS 3DEP / National Map | Elevation samples, gain/loss, slope/effort inputs. | Browser fetch to USGS 3DEP; Open-Elevation fallback outside US. | Public-domain USGS; Open-Elevation has its own terms. | High for US elevation context. | Sampling is approximate; not a navigation-grade elevation profile. | Attribute as elevation model; warn values are approximate. | Medium. |
| Open-Meteo | Short-range forecast. | Browser fetch in `weatherService.ts`. | Review Open-Meteo terms before production/commercial scaling. | Medium for near-term weather. | Forecast horizon limited; historical climate normals not integrated. | Show as forecast summary, not official safety clearance. | Medium for near-term weather. |
| NIFC WFIGS | Active wildfire incident and perimeter context. | ArcGIS REST feeds in `forestAlertService.ts`. | Public interagency fire feeds; attribution should name WFIGS/NIFC. | High for fire-risk warning context. | Does not prove trail closure status; closures still require land-manager check. | Show fire alert warnings and direct users to official closures. | Medium-high for active fire context. |
| NPS API / data | Not currently integrated. Planned for park alerts, campgrounds, boundaries, permits. | TODO connector. | NPS API key/terms apply. | High future source for NPS areas. | Missing today. | Preserve park unit, alert URL, last updated. | TODO. |
| BLM geospatial data | Not currently integrated. Planned for public land boundaries/recreation context. | TODO connector. | Public federal datasets vary by layer. | Medium-high future source in western US. | Missing today. | Preserve BLM layer/source URL. | TODO. |
| State/local GIS portals | COTREX is integrated for Colorado; other states are TODO. | ArcGIS/open data per jurisdiction. | Terms vary by portal. | Medium future source. | State-specific schemas. | Preserve agency/source URL. | TODO. |
| AllTrails / Trailforks / Gaia / Komoot / Hiking Project | Outbound links only; UX research / manual comparison only. | No backend ingestion. | Do not scrape or depend on without explicit license. | Not a backend source. | Proprietary/community data; terms restrict reuse. | If linked, label as external reference, not TrailScout data. | Not used for scoring. |

## Current Attribution Rule

Runtime `TrailData.tags.trailscout_source` is mapped through `src/utils/sourceAttribution.ts` into a lightweight attribution record: primary source, source kind, URL if available, confidence, and warnings. Any new source connector should set `trailscout_source`, source IDs, source URL, and last-updated tags when available.
